**Gene Expression Scout is an agentic AI-powered transcriptomics research tool.**

Provide the system with a species name, biological factor and genes of interest, and the system retrieves relevant gene expression data.

Created by Brady Johnson-Hill at Oakland University. Contact: [email](mailto:bjohnsonhill@oakland.edu)

> [!NOTE]
> This project is still under development. Please let us know if you encounter anything unusual!

## Install notes
- Prior to running, you must download the file [go-basic.obo](http://purl.obolibrary.org/obo/go/go-basic.obo) from Gene Ontology, and move it into the gene_expression_scout folder.
  - This file is used in determining the depth of Gene Ontology terms.
